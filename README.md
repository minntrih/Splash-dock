# Splash Dock

> A premium, macOS-style standalone dock for Linux — built with Qt 6, QML, KDE Frameworks 6, and the Wayland Layer Shell protocol.

---

## Features

| Feature | Implementation |
|---|---|
| **Screen anchoring** | `zwlr_layer_shell_v1` — dock locks to the bottom, maximized windows never overlap |
| **Frosted glass blur** | `KWindowEffects::enableBlurBehind` — KWin compositor blurs behind the dock surface |
| **Noise overlay** | Procedural GLSL fBm shader (`noise.frag`) — no PNG texture needed |
| **Saturation boost** | GLSL HSL shader (`saturation.frag`) applied as a Qt layer effect |
| **Physics magnification** | `SpringAnimation` + Gaussian proximity falloff — replicates macOS Dock wave |
| **Drop shadows** | `QtQuick.Effects.MultiEffect` — hardware-accelerated, no QGraphicsDropShadow |
| **Pure Wayland** | Zero X11 / xcb / XChangeProperty — runs only on Wayland sessions |

## Dependencies

### Required

```
Qt 6.6+                  # Core, Gui, Qml, Quick, WaylandClient, ShaderTools
KDE Frameworks 6.0+      # KF6::WindowSystem  (for KWindowEffects)
wayland                  # libwayland-client
wayland-scanner          # Wayland::Scanner (from the system wayland package)
CMake 3.22+
```

### On CachyOS / Arch

```bash
sudo pacman -S qt6-base qt6-declarative qt6-wayland qt6-shadertools \
               kf6-windowsystem cmake wayland wayland-protocols extra-cmake-modules
```

> **Note**: `wlr-protocols` (the layer-shell XML) is **bundled** in `protocols/` — you do **not** need to install it.

## Build

```bash
# 1. Clone
git clone <repo-url> splash-dock && cd splash-dock

# 2. Configure  (Release for production, Debug for development)
cmake -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo

# 3. Compile
cmake --build build -j$(nproc)
```

---

## Run

**You must be on a Wayland session with KWin as the compositor** (KDE Plasma 6 on Wayland satisfies this out of the box).

```bash
./build/splash-dock
```

Expected behaviour:
- A frosted-glass dock bar appears at the bottom of your primary display.
- Maximized windows stop at the dock's top edge.
- Moving the mouse over icons triggers the spring-physics magnification wave.
- KWin blurs the desktop/windows visible behind the dock.

## Architecture Notes

### Why no X11?

All blur, anchoring, and compositor communication goes through Wayland protocols:

- **Layer anchoring** → `zwlr_layer_shell_v1` (wlroots protocol, supported by KWin since Plasma 5.27)
- **Background blur** → `org_kde_kwin_blur` (KWin-specific Wayland protocol, exposed via `KWindowEffects`)

No `xcb.h`, `KX11Extras`, or `XChangeProperty` is used anywhere.

### Wayland Scanner Flow

```
protocols/wlr-layer-shell-unstable-v1.xml
    │
    ├─ wayland-scanner client-header  →  wayland-wlr-layer-shell-…-client-protocol.h
    ├─ wayland-scanner public-code    →  wayland-wlr-layer-shell-…-protocol.c
    ├─ qtwaylandscanner client-header →  qwayland-wlr-layer-shell-….h   (C++ bindings)
    └─ qtwaylandscanner client-code   →  qwayland-wlr-layer-shell-….cpp
```

All generated by `qt6_generate_wayland_protocol_client_sources()` in CMakeLists.txt.

### Shader Compilation

```
shaders/noise.frag  ──qsb──►  build/.../noise.frag.qsb   (embedded in Qt resources)
shaders/saturation.frag ──►  build/.../saturation.frag.qsb
```

`qt6_add_shaders` cross-compiles GLSL 440 to SPIR-V / MSL / HLSL / GLSL ES depending on the RHI backend active at runtime.
